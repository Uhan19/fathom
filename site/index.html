Why Fathom

Keeping track shouldn’t be your job

Fathom’s mission is to take the work of keeping track off your mind. Your agents do the work, Fathom keeps the picture, and you stay on top of everything without carrying it in your head.

01

Nothing to remember

Tasks show up on the board as your agents take them on, and move as they progress. You never need to update it by hand. If you move a card yourself, the agent is asked and acknowledges it.

02

Read it in a glance

Depth tells you the state. What needs you floats up. Everything lower is already in hand.

03

Keep handing off

Give your agents the next task whenever it comes to mind. The board takes the weight, not you.

How it works

Everything in its place

Fathom sorts every task by what it needs from you. Read from the top: what needs you first, then everything that is already in hand.

Surface

Only what needs you, at the top

Questions and decisions from your agents rise to the top row, marked in yellow, and the header counts them. Everything below can wait, so you always know where your attention goes next.

Shallows

Progress without checking in

Tasks a sub-agent is working on sit in the shallows. A small sailor marks each one, and its visor glows while it works, so you can see work moving without asking. Click it to open that sub-agent’s live terminal.

Deep and Seabed

Queued, parked and blocked, out of your head

Parked work, or work held until a date, waits in the deep. Queued work rests on the seabed, with any tasks it is waiting on named on the card. None of it is yours to remember.

Drag to ask

Change the plan by dragging

Drop a card in another row and Fathom asks the agent to move the task. The card waits with an Asked tag until the agent says yes, or answers with a reason. Nothing moves without the agent knowing.

Chat

Keep handing off work

The agent’s real terminal sits beside the board: Firstmate, Claude Code or Codex. Give it the next task whenever one comes to mind. The board shows it as soon as the agent takes it on.

Bosun

Change Fathom in plain words

Ask Bosun to show only one project, collapse columns or switch to dark mode. It uses only Fathom’s own tools and asks before risky changes.

Landed

A clear record of what got done

Finished work lands at the bottom with its pull request linked, newest first, so the end of the day has a record you didn’t have to keep.

Install

With your agent. Paste the setup prompt into Codex or Claude Code. It installs Fathom and what it needs, and asks before every install.

macOS. Open the .dmg and drag Fathom into Applications. Fathom needs macOS 13 or newer.

Linux. Install the package, or make the AppImage executable and run it:

sudo apt install ./Fathom_amd64.deb
chmod +x Fathom_amd64.AppImage && ./Fathom_amd64.AppImage

What you need

Fathom is the board. These tools do the work it shows. Install them first.

herdr-core Required

Runs the live terminals for the chat, crewmates and Bosun, through the herdr-core command. They keep running after Fathom quits. The header shows a green dot when Fathom can reach it.

curl -fsSL https://releases.herdr.dev/core/install.sh | sh

Claude Code For Bosun and chat

Bosun runs on Claude Code, and it can be your chat agent. It needs a paid Claude plan or a Claude Console account.

curl -fsSL https://claude.ai/install.sh | bash

Codex Optional

Works as a chat agent instead of Claude Code. Follow the install steps in its README.

Firstmate Recommended

An agent setup that runs a crew of coding agents for you, and the recommended way to use Fathom. Fathom shows its tasks. Without it, Fathom keeps its own backlog. Firstmate needs git and the GitHub CLI.

gh auth login
git clone https://github.com/kunchenguid/firstmate ~/Documents/firstmate
cd ~/Documents/firstmate && claude

Where tasks come from

Fathom with Firstmate is the recommended way to use it.

With Firstmate. Fathom finds Firstmate in ~/Documents/firstmate; if it lives elsewhere, set the Firstmate home folder in Settings. Fathom reads tasks through bin/fm-tasks-axi.sh in that folder and never changes the task list.

Without Firstmate. Leave the Firstmate home empty. Fathom keeps a local backlog that any agent fills through Fathom’s MCP server. Add it to your agent:

# macOS
claude mcp add --scope user fathom -- /Applications/Fathom.app/Contents/MacOS/fathom --mcp
# Linux, after installing the .deb
claude mcp add --scope user fathom -- /usr/bin/fathom --mcp

Claude Code and Codex get the server on their own when you open them from the chat panel.

The board updates live as tasks change. There is no refresh button.

The five rows

RowWhat it holds
SurfaceNeeds you: a question or a decision.
ShallowsIn progress now.
DeepParked, or held until a date.
SeabedQueued, including work waiting on other tasks.
LandedDone, newest first.

Each project starts as a column. Rename, reorder, resize or collapse columns, and rename rows in Settings.

Moving cards

Drag a card within its row to reorder it. Drag it to another row and Fathom asks the agent to move the task. The card stays put with an Asked tag until the agent agrees. If the agent declines, the tag becomes Answered with its reply. If the request could not be sent, it shows Not sent with a button to try again.

Crewmates

A small sailor on a card means a sub-agent is working on that task. Its visor glows while it works and dims while idle. Click the sailor to open that sub-agent’s live terminal.

Chat panel

The chat panel beside the board is the agent’s real terminal. It attaches to the terminal labelled firstmate.role=primary on a Firstmate home, or fathom.role=chat on Fathom’s own backlog. If there isn’t one, open Claude Code, Codex or Firstmate from the panel, or pick a running terminal. Click a card and use “Message Firstmate about this card” to send it a note.

Bosun

Bosun changes Fathom itself when you ask in plain words: columns, rows, which projects show, the theme, fonts and panels. It runs Claude Code with only Fathom’s own tools, and asks before risky changes. Open it with ⌘J on macOS or Ctrl+J on Linux.

Customize

  • Columns. Each project starts as a column. Add, delete, rename, reorder and resize columns, and collapse one to a thin strip with its name and count.
  • Rows. Rename rows in Settings, and collapse one to a thin band with its name and count. The rows are Surface, Shallows, Deep, Seabed and Landed.
  • Fonts. Set the board font and size, and the chat font and size, separately, in Settings.
  • Theme. Switch between light and dark.
  • Ask Bosun. Bosun can hide or show the chat panel and show only the projects you name.

Or ask Bosun in plain words, for example “rename Surface to Needs me” or “make the chat font bigger”.

Settings and data

Settings holds the Firstmate home, the herdr-core chat label, agent folder, session and socket, the chat and board fonts and sizes, and the row names. Fathom keeps its layout in a local SQLite file. Settings shows its size and location, and exports everything as JSON and CSV.
