# Symbols Nerd Font Mono

Fathom's terminals use this font as the last fallback, so Nerd Font icons in shell prompts draw whichever terminal font is chosen.

## Source

- Release: Nerd Fonts v3.5.1
- Archive: https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.1/NerdFontsSymbolsOnly.zip
- Archive SHA-256: `fdca3682534f6f65e1ccb2345b0362ccf67d9b8eca7c8025330946e93e2473bc`
- Font in the archive: `SymbolsNerdFontMono-Regular.ttf`, SHA-256 `fe471e538392f51910faab985fa8e192a39dd3426125edd15b71b3680df0e749`
- Shipped file: `SymbolsNerdFontMono-Regular.woff2`, SHA-256 `5ac9b97de5fe886f300303c8b59954624926c6a7174a1fbbed762e8f4ba2ad5b`

The woff2 is a lossless repackaging of the TTF made with fontTools 4.68.0 (`TTFont(ttf)`, `flavor = "woff2"`, `save`).
The glyphs, the character map and the font names are unchanged.

Nerd Fonts changed some glyphs from their upstream sets, as its glyph READMEs describe.
Codicons, Font Awesome and Material Design Icons glyphs were fixed or remixed, and Powerline glyphs were widened by a few percent.
The CC BY 4.0 attribution is to Microsoft (Codicons) and Fonticons, Inc. (Font Awesome), with those changes made by Nerd Fonts.
The font keeps its own name, "Symbols Nerd Font Mono", so no Reserved Font Name is used.
